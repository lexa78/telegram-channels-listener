# Бот слушает telegram каналы и отправляет все сообщения в очередь.
## Первый запуск бота
Билд  
```
docker compose build
```
Запуск в интерактивном режиме  
```
docker compose run --rm --service-ports bot bash
```
Внутри контейнера `root@container:/app#`  
```
php index.php
```
Нужно будет ввести номер телефона и полученный код  
После этого будет сформирована и сохранена сессия пользователя  
При последующих запусках контейнера обычный `docker compose up`
